## Publish to GitHub Pages

You already have the repo: <https://github.com/v445u/v445u.github.io>, and Pages is already enabled.

1. Copy the files above into the **root** of that repository.
2. Commit and push to `main`.
3. Your site goes live at **<https://v445u.github.io>** (usually within a minute).

If you ever need to enable Pages manually: repo → **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/root` → Save**.

## Preview locally

```bash
cd this-folder
python -m http.server 8000
```

Then open <http://localhost:8000>.
